記憶ラボ Ver.13 — スマホ操作性改善版

同梱ファイル
- index.html: 公開サイトの入口
- kioku_lab_prototype.html: index.htmlと同じアプリ本体
- manifest.json: PWAの表示名・起動画面・アイコン設定
- sw.js: キャッシュとオフライン起動の補助
- icon-192.png / icon-512.png: ホーム画面アイコン
- .nojekyll: GitHub Pages用
- kioku_lab_v13_CHANGELOG.txt: 主な変更点

Ver.13の変更
- スマホではメインメニューを画面下に固定し、画面切り替えをしやすくした
- ボタンや入力欄のタップ領域、フォーカス表示、余白、文字サイズ、コントラストを改善
- 単語管理のサブメニューを横スクロール可能にし、小さい画面で折り返しにくくした
- 回答前に自信度（自信あり／少し不安／勘・不明）を任意で記録できるようにした。未選択時は従来の回答速度等から推定
- 分析画面に単語帳・学習モード別の回答数、正答率、平均回答時間を追加
- 四択の解答後に7秒で自動遷移する挙動を停止し、自分のペースで解説確認後に次へ進めるようにした
- タブのアクセシビリティ属性とキーボードのフォーカス表示を改善
- PWAキャッシュ名をkioku-lab-v13に更新
- 既存データ引き継ぎのため、localStorageの保存キー kioku-lab-v1 は維持

公開方法
- すべてのファイルをGitHubリポジトリのルート（一番上の階層）にアップロードする
- GitHub Settings → Pages で Deploy from a branch、main、/(root) を選ぶ
- 公開URLは通常 https://ユーザー名.github.io/リポジトリ名/ の形式
- HTMLファイルを直接開くのではなく、HTTPSの公開URLをChromeで開くとPWA追加の対象になる場合がある

データ保護
- 学習履歴は通常その端末・ブラウザのローカルストレージに保存されます
- 古いURLと公開URL、別ブラウザ、別端末では保存領域が異なるため、移行時はアプリの「データ」からJSONを書き出し・復元する
- JSONのバックアップや単語データを公開リポジトリにアップロードしない
- Excel取り込みはSheetJS CDNを使うため、xlsxライブラリのダウンロードにインターネット接続が必要。CSVの利用も可能
- 自動クラウド同期は未実装

注意
- このパッケージは実機Android Chromeでの操作をこちらから確認できていない。公開後に端末で確認すること
- 復習間隔・習得判定はヒューリスティックであり、科学的に最適な結果を保証しない
